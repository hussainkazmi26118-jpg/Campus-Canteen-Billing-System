
# Campus Canteen Billing System

## Description
A simple Python program that calculates customer bills
for a campus canteen.

## Menu
- Burger: PKR 300
- Pizza: PKR 500
- Sandwich: PKR 200
- Tea: PKR 100

## Features
- Multiple item orders
- Quantity-based billing
- Checkout using 0
- 10% discount on bills of PKR 1,000 or more
- Displays subtotal, discount, total quantity, and final bill

## Requirements
Python 3

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

   python canteen_billing.py
